# One Job and a Hostage

An entry for **Angry Judge: The Short Rant Contest**.

> My printer has one job and a hostage. It ate my return label, demanded cyan to print black, then told me to 'check the paper path' like I'm tracking a missing hiker. I've opened six flaps; apparently the seventh needs a UN resolution. It wants diplomatic immunity. Fine. The next return label goes on the printer.
